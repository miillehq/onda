# Brand files

Unchanged copies of files from the Onda and miille brand kits, for the README and the images
`npm run readme:images` generates. Use them as they are: no recolouring, redrawing, stretching
or added effects.

| File | Used for |
| --- | --- |
| `onda-icon-dark-512px.png` | The app icon at the top of the README (the dark icon is the default) |
| `onda-lockup-black.svg`, `onda-lockup-white.svg` | The name with the mark; black on light, white on dark, at least 100 px wide |
| `onda-mark-black.svg`, `onda-mark-white.svg` | The mark alone, at least 14 px tall, in the window frames of the screenshots |
| `miille-horizontal-black.svg`, `miille-horizontal-white.svg` | "Onda by miille" at the end of the README, at least 120 px wide |

Keep clear space around a logo: the height of its lowercase letters for the lockup, half its
height for the mark. In text, write **Onda**, or **Onda by miille** where the parent brand
should show. The full kits, with every size, format and the logo guidelines, are kept by the
owner; ask in an issue if you need another file.
