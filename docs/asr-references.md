# ASR research references

Inspected on 3 October 2026. No third-party implementation was copied into Eagle;
native libraries are dependencies and the public speech fixture retains provenance.

| Primary source inspected | Evidence and decision |
| --- | --- |
| [whisper.cpp source](https://github.com/ggml-org/whisper.cpp/blob/v1.8.3/src/whisper.cpp), [CPU build configuration](https://github.com/ggml-org/whisper.cpp/blob/v1.8.3/ggml/src/ggml-cpu/CMakeLists.txt), [Vulkan build](https://github.com/ggml-org/whisper.cpp/blob/v1.8.3/ggml/src/ggml-vulkan/CMakeLists.txt) | CPU support, quantized GGML weights, wide Windows model paths and cross-vendor Vulkan. Native tuning is unsuitable for a universal baseline. Choose isolated Whisper CPU plus optional isolated Vulkan. |
| [whisper-rs maintained repository](https://codeberg.org/tazz4843/whisper-rs), [0.16.0 package](https://crates.io/crates/whisper-rs/0.16.0), [0.15.0 sys package](https://crates.io/crates/whisper-rs-sys/0.15.0) | Inspected actual downloaded `build.rs`, context/parameter/segment wrappers and `vulkan.rs`. Bindings expose GPU device enumeration, explicit CPU selection and vocabulary prompt. Rust wrappers are Unlicense; vendored whisper.cpp is MIT. |
| [transcribe-rs Cargo features](https://github.com/cjpais/transcribe-rs/blob/main/Cargo.toml), [Parakeet implementation](https://github.com/cjpais/transcribe-rs/blob/main/src/onnx/parakeet/mod.rs), [ONNX session construction](https://github.com/cjpais/transcribe-rs/blob/main/src/onnx/session.rs) | Current source identifies 0.3.11, MIT, optional ONNX and Whisper backends; inspected separate encoder/decoder/preprocessor and provider/thread policies. Useful future integration, but a direct Whisper binding minimizes dependencies for the initial universal CPU path. |
| [ONNX Runtime license](https://github.com/microsoft/onnxruntime/blob/main/LICENSE), [DirectML provider documentation](https://onnxruntime.ai/docs/execution-providers/DirectML-ExecutionProvider.html) | ORT is MIT. DirectML needs DX12 and Windows10 1903+; provider sessions require sequential execution and disabled memory patterns. Strong cross-vendor candidate for a separately validated ONNX engine, not automatically interchangeable with GGML Whisper. |
| [NVIDIA Parakeet v2 model card](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v2), [v3 model card](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3) | Both current cards license the weights CC BY4.0; v2 English and v3 multilingual. Attribution and conversion provenance are independent of the application's license. Third-party conversions may carry different restrictions. Not distributed in this catalog; first prove low-hardware Whisper rather than impose another large runtime/model bundle. |
| [whisper.cpp acceleration documentation](https://github.com/ggml-org/whisper.cpp/blob/master/README.md#vulkan-gpu-support) | Vulkan covers NVIDIA/AMD/Intel where the driver/backend supports required features. CUDA is NVIDIA-specific and has toolkit/runtime distribution costs. Vendor detection alone is insufficient; Eagle probes the actual optional worker and keeps CPU available. |
| [Whisper model license](https://github.com/openai/whisper/blob/main/LICENSE), [GGML model metadata](https://huggingface.co/api/models/ggerganov/whisper.cpp?blobs=true), [pinned model repository](https://huggingface.co/ggerganov/whisper.cpp/tree/5359861c739e955e79d9a303bcbc70fb988958b1) | Whisper weights and upstream code are MIT. Pinned revision, exact LFS byte sizes and SHA-256 form the trust root; downloaded tiny.en and quantized base.en independently verified. Model rights remain separate from Apache2 Eagle code. |
| [Microsoft DXGI adapter enumeration](https://learn.microsoft.com/en-us/windows/win32/api/dxgi/nf-dxgi-idxgifactory-enumadapters), [RAM API](https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/nf-sysinfoapi-globalmemorystatusex) | Device evidence belongs in native code; distinguish software adapters, dedicated memory and integrated shared memory. Physical CPU topology comes from `num_cpus` Windows implementation. |
| [LunarG Vulkan SDK](https://vulkan.lunarg.com/sdk/home) | Build tooling only; not an end-user requirement. Official signed1.4.363.0 SDK's compiler, headers and import libraries were used for local validation. No SDK or build-tool binaries are committed or bundled in Eagle. |
| [Microsoft runtime redistribution](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files?view=msvc-170), [deployment options](https://learn.microsoft.com/en-us/cpp/windows/deployment-in-visual-cpp?view=msvc-170) | Release workers import the VC++ runtime. Licensed app-local redistribution supports per-user installation; the project must service those DLLs with its releases. Central installation receives independent Microsoft servicing but ordinarily needs elevation. |
| [JFK Presidential Library transcript](https://www.jfklibrary.org/archives/other-resources/john-f-kennedy-speeches/inaugural-address-19610120), [upstream audio fixture](https://github.com/ggml-org/whisper.cpp/blob/b0a11594aec50892a02cd8d129eee2dfe93a8bb8/samples/jfk.wav) | Known public US government speech, checked-in11-second PCM16 fixture, exact checksum and semantic criteria. See `tests/fixtures/asr/README.md`. |

The chosen stack introduces no GPL/AGPL runtime. `whisper-rs`/sys are Unlicense,
the native MIT notices and OpenAI Whisper model MIT notice must ship in third-party
notices. ONNX Runtime, transcribe-rs and Parakeet are researched alternatives,
not distributed Eagle dependencies. Research conclusions do not certify every
driver, CPU or third-party model conversion.
