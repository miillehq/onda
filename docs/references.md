# Source research and provenance

Research performed 2026-10-03, using actual source and primary documentation. No competitor source, strings, branding or artwork were copied into Eagle. The source checkouts under ignored `.research/` are research inputs only and are not part of the distribution.

| Reference | Inspected material | Consequence |
|---|---|---|
| [WhimprFlow](https://github.com/Blueturboguy07/WhimprFlow/tree/04d477a75278fd4f8e6e25f55a34d7733d9d393b) (MIT) | src-tauri/src/win.rs, autolearn.rs, core/dictionary/mod.rs, Cargo manifests; docs/research/win-insertion.md, win-gap-critic.md, gap-auto-learned-dictionary.md, stack-decision.md and gap-model-verification.md | Useful decomposition and vocabulary/replacement ideas. Windows source marks integration unverified, uses globals and text-only unconditional clipboard restoration. Research contains hypotheses and platform claims, not evidence of a tested release. Eagle implements guarded clipboard transactions, UUID state generations, migrations and independently compiled Windows tests. |
| [Handy](https://github.com/cjpais/Handy/tree/5ec58f696354fcf64ae831102e673779e0249717) (MIT) | paste_tx/windows.rs, clipboard.rs, shortcut/handy_keys.rs, audio/model/transcription managers and catalog | Current Windows paste transaction demonstrates delayed-render read receipts and full-format preservation. Eagle's implementation is independently written, with explicit fail-safe format/refocus decisions and a smaller Windows-only boundary. Reading only Handy's legacy clipboard path would miss its stronger current transaction. |
| [VoiceInk](https://github.com/Beingpax/VoiceInk/tree/c09cc1f677f40f2ee665843a61f07670210f012e) (GPL-3.0) | License, dictionary replacement variants, provider/prompt structure and model/mode concepts | Design research only. No source or assets reused, and no GPL dependency introduced. Avoid cascaded deterministic replacements; separate exact spelling from explicit correction. macOS APIs are not implemented here. |
| [Wispr Flow dictionary](https://docs.wisprflow.ai/articles/4052411709-Teach-Flow-your-words-with-the-dictionary), [workflow](https://docs.wisprflow.ai/articles/2772472373-what-is-flow) and [privacy](https://docs.wisprflow.ai/articles/3467817258-security-and-compliance-faq) | Public workflow documentation | Hold/release, personal vocabulary and recurring correction are useful category concepts. Eagle's local ASR and opt-in context differ from cloud dictation. No proprietary implementation or branding reused. |
| [Tauri Windows installer](https://v2.tauri.app/distribute/windows-installer/), [prerequisites](https://v2.tauri.app/start/prerequisites/), [updater](https://v2.tauri.app/plugin/updater/) and [capabilities](https://v2.tauri.app/security/capabilities/) | Official docs, fetched plus resolved crate schemas/API source | Per-user NSIS, WebView2 bootstrap, narrow IPC permission and separate update-signature hooks. |

Native input/audio/UIA/clipboard/credential sources and exact API caveats are in [native references](native-references.md). ASR engines/model licenses/hardware providers and pinned manifests are in [ASR references](asr-references.md). OpenAI's current official OAuth and Responses requirements, fetched at implementation time, are in [OpenAI references](openai-references.md). These source-specific documents avoid treating estimated performance or library claims as measured facts.
